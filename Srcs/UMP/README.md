# USB Mouse Proxy - UMP
## USBマウスプロキシ

PCからはHIDマウスとして動作し、逆のポートに接続したマウスの動作を置き換えます。

現状は ELECOM HUGE PLUS M-HT1MRBK (かつ、俺スタイル) 特化のコンフィグレーションとなっており、再ビルドする以外にコンフィグレーションを変更する手段はありません。バージョンアップに期待！

## 存在意義・動機
勤務先の作業環境が多少特殊で、エレコム マウスアシスタントが使用できません。が、 ***トラックスクロールがどうしても欲しい。*** ていうかマウスアシスタントにはそもそも ***トラックスクロールがござらん。***

## 使用方法(ボードへの書き込み)
まずビルドしてください。PlatformIOでのビルドについては割愛します。<br>

Picossci USBホスト は、 BOOTSEL を押したまま RESET を押下->放すと、(要するに立ち上げ時 BOOTSEL が押されていると) USBドライブとしてマウントされます。<br>
マウントされたUSBドライブに、ビルドの結果生成された .pio\build\ump\firmware.uf2 をコピーすることで書き込まれます。
